# Great Writing Apps

A responsive, Kahoot-style spelling quiz for **Great Writing Foundations — Unit 2, Activity 10**.

## Features

- 20 randomized two-choice spelling questions
- Restart-on-error mastery flow
- Teacher answer-key mode
- Responsive and keyboard-accessible interface
- Static site: no build step required

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Teacher mode

The classroom password is `1004`. This is a client-side teaching aid, not a security boundary.
